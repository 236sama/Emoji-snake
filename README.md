# Emoji-snake
이모지로 그래픽을 만든 뱀 게임. / A snake game whose graphic consists of emojis.

## How to Play
일반적인 스네이크와 플레이 방법 ~~유전자~~ 자체는 같습니다. / Just the same with how you play normal snakes ~~because they got the same DNA~~.

그래도 설명이 필요하시다면... / Still, for some of you who need further explanation...

- WASD, 또는 상하좌우 키로 뱀(😀🟡🟡🟡)을 조종합니다. / WASD, or arrow keys to move your snake(😀🟡🟡🟡)

- 체리를 먹어서 길어지세요.🍒 / Eat cherries to grow longer

- 벽이나 자기 몸에 닿으면 죽습니다.😵 / You are out when you touch the wall or yourself.😵
